# 91 影音 · DIAN115 插件

适用于 DIAN115 插件 API 3.8 及以上。影片库显示来源接口返回的分类和搜索结果，支持附件定义的 59 个分类、封面、详情和 HLS 播放。播放线路以来源详情接口当次返回的地址和权限状态为准。

## 网页观看

在 DIAN115 插件中心导入安装包，启用后点击「打开」。进入影片详情可播放，有多条线路时可以切换。Safari 使用原生 HLS，Chromium 等支持 MSE 的浏览器使用随包交付的 hls.js。播放控件提供全屏、音量和进度调整。

## 外部播放器

1. 在「播放器连接」创建独立账号并复制本次生成的密码。
2. 选择监听范围和端口后开启监听。Docker 部署时映射该端口。使用反向代理时，在客户端填代理后的地址。
3. 在客户端选择 Emby，填写显示的服务器地址和账号密码。支持 Emby API Key 的客户端也可使用「显示 API Key」中的值。
4. 重新生成密码会使旧令牌失效。页面可随时关闭监听。

Emby 中的 59 个媒体库带有插件内置的分类封面。

兼容服务提供服务器信息、认证、分类、分页、搜索、详情、封面、PlaybackInfo 和逐影片播放进度。PlaybackInfo 提供来源的 HTTPS 播放地址。使用 Emby 标准播放入口的客户端会跳转到该地址，播放器需要能直连源站并播放 HLS。

运行 `npm test` 可验证接口契约。播放库许可见 `ui/vendor/hls.LICENSE`。
